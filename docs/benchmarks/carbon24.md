# Carbon-24

About 10,000 carbon structures with up to 24 atoms per cell (CDVAE split). In the MEIDNet paper it is the second structure-representation generalization test; no property modality and no checkpoint here.

**10,153 materials** · split: CDVAE: 6,091 train / 2,031 val / 2,031 test · [dataset source](https://github.com/txie-93/cdvae/tree/main/data/carbon_24)

## No protocol yet

The paper uses this dataset for structure-representation results; no benchmark protocol has been defined for it yet. A protocol is a `protocol` section in `benchmarks/datasets/carbon24.json` with its tasks, settings and metrics: [Perov-5](perov5.md) is the template ([how to add a dataset](../community/contribute.md#add-a-dataset)).
