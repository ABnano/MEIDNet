# MP-20

About 45,000 Materials Project structures with at most 20 atoms per cell (CDVAE split). In the MEIDNet paper it tests how the crystal encoder and decoder generalise beyond perovskites; no property modality was aligned on it and no MP-20 checkpoint is shipped in this repository.

**45,231 rows** · split: CDVAE: 27,136 train / 9,047 val / 9,046 test · role in the paper: published: structure-representation generalization (not a multimodal benchmark) · [dataset source](https://github.com/txie-93/cdvae/tree/main/data/mp_20)

!!! note "Read a row"
    Rows are compared only within this dataset and category. The ladder ●○○○○ … ●●●●● is the
    evidence level (generated → ML filtered → MLIP validated → DFT validated → experimentally validated).
    *Published* = taken from the paper; *MEIDNet verified* = reproduced here from the submitted configuration.
